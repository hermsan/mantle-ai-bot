# Mantle AI Assistant - Advanced On-Chain Intel & Alpha Agent

An AI-powered Telegram Bot designed for the Mantle Network ecosystem, acting as an automated intelligence agent for developers and on-chain analysts to hunt alpha and audit transactions.

## 🚀 Track Alignment: AI Alpha & Data / AI DevTools
This project directly solves the problem of analyzing raw, unreadable blockchain metadata. By combining Mantle Network RPC nodes with Google's state-of-the-art Gemini 2.5 Flash architecture, the bot transforms complex hexadecimal blockchain data into readable, structured financial intelligence.

## ✨ Core Features
- **Instant Diagnostic Monitoring (`/block`, `/gas`)**: Real-time validation of Mantle Network state and execution costs.
- **On-Chain Asset Auditing (`/wallet`)**: Instantly parse and query live MNT balances across any valid Mantle address.
- **Anomaly & Smart Money Breakdown (`/analyze`)**: Decodes smart contract transactions to identify anomalies, token transfers, and potential whale actions using AI.
- **Interactive Web3 Copilot (Free Chat)**: An LLM-powered environment strictly calibrated to provide English-only infrastructure insights about Mantle DeFi.

## 🛠️ Technology Stack
- **Network Core**: Mantle JSON-RPC
- **AI Engine**: Google GenAI SDK (Gemini 2.5 Flash)
- **Framework**: Python 3.x (Telebot architecture)
- **Deployment**: Scaled via Hugging Face Spaces (Production Grade)
